# Platform icon sources

These files are unmodified SVG assets retrieved from the [Simple Icons](https://simpleicons.org/) package via jsDelivr on 2026-08-12. They replace the prior hand-authored approximations.

- `apple.svg` — Simple Icons slug `apple`; used for macOS and iOS.
- `windows11.svg` — Simple Icons slug `windows11`; used for Windows.
- `linux.svg` — Simple Icons slug `linux`; used for Linux.
- `android.svg` — Simple Icons slug `android`; used for Android.

Source URL pattern: `https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/<slug>.svg`
