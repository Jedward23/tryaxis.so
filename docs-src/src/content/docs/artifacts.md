---
title: Artifacts and collections
description: Turning agent output into files you can open, read, and keep.
---

Some results deserve more than a chat bubble. An artifact is a file a session produced
that you can open beside the conversation — a report, an image, a document, a diagram,
a mockup, or a small interactive tool.

## What becomes an artifact

| Kind | Example |
| --- | --- |
| Document | A written report or summary |
| Image | A screenshot, diagram, or generated picture |
| Data | Structured output worth keeping |
| Interactive | A self-contained page you can click through |

Artifacts belong to the session and project that created them.

## Two ways they appear

**On request.** Ask for a report, mockup, or document and the agent creates it as an
artifact directly.

**On click.** When an agent mentions a file it produced, that path appears as a link.
Clicking it copies the file into the session's collection and opens it.

The second matters: an agent that writes fifty intermediate files does not flood your
workspace with fifty artifacts. You promote the ones you care about.

## Editing

Markdown artifacts are working documents, not read-only previews. Edit them in place —
a plan you asked for is something you can revise rather than only read.

## Collections

Artifacts collect per project, so you can find what was produced without remembering
which session made it.

Opening one from the collection reopens it in its pane.

## Inline results

Not everything needs a file. For compact or transient output, agents render results
directly in the transcript:

- Status cards and progress
- Tables of structured results
- Comparisons and metrics
- Small interactive widgets
- Message and email drafts, with edit and copy

This is the default for small things. Artifacts are for output that is durable,
large, file-like, or explicitly requested.

## Drafts

When an agent writes a message, email, or post for you, it appears as an inline draft
card with the recipient and subject, and an editable body.

Drafts are drafts. Nothing is sent without your say-so.
