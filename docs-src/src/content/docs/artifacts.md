**Learn lane · Mission: keep the result worth returning to**

Collections is the project-scoped home for durable saved material. An artifact is one
kind of saved item—such as a document, image, dataset, or interactive file—not a
separate competing destination.

## Decide what deserves to persist

Keep an output in Collections when it is durable, file-like, large, reusable, or
explicitly requested:

| Saved material | Example |
| --- | --- |
| Document | Research report, brief, plan, or reconciliation |
| Image | Approved design, diagram, or proof image |
| Data | Structured export worth reopening |
| Interactive | Self-contained mockup, chart, or lightweight tool |

Small status, comparison, table, or draft content can stay inline in the transcript.
Not every result needs a file.

## Promote deliberately

A session may create many intermediate files. Axis should not flood Collections with
every path. A supported result path can appear as a link; opening it promotes that
specific file into the creating session/project and opens the saved item.

Agents can also create and open a Collection item directly when the requested
deliverable is itself a durable artifact.

## Keep provenance attached

A saved item should retain enough context to answer:

- Which project owns it?
- Which session created or promoted it?
- What source file or workflow produced it?
- What type is it, and when was it saved?

Opening the source session lets you inspect the request and evidence rather than treating
the output as context-free truth.

## Edit working documents

Markdown items can be working documents, not only read-only previews. Editing the saved
copy should be deliberate and should not be confused with silently changing the
original source file when those are separate resources.

## Inline drafts remain drafts

Message, email, or post drafts may render as editable cards in the transcript. They are
not sent by appearing, editing, or copying. Sending remains a separate consequential
action with its own authorization boundary.

## Search the collection, not your memory

Use project scope, type filters, provenance, and source-session links to find durable
material. This removes the burden of remembering which chat produced a report or where
an image path was written.

## Mission complete when

You can find a durable result from the project, open it beside the exact source session,
inspect its provenance, and revise it without promoting every intermediate file.
