---
title: Mobile
description: Your real workspace on a phone or tablet — not a cut-down status view.
---

Axis on mobile is the same workspace, not a read-only companion. It is built for the
gaps between deep work: check what finished, unblock an agent, review something, take
over a browser.

## Getting connected

Mobile connects to the Axis running on your own machine. There is no separate cloud
copy of your work.

The first launch asks you to pair with your node. See [Remote access](/docs/remote-access/)
for how that connection is established.

## What you can do

| | |
| --- | --- |
| Read any session | Full transcript, including folded work and evidence |
| Send and steer | Compose, queue, and interrupt |
| Answer approvals | Everything in the inbox works on mobile |
| Review artifacts | Reports, images, documents |
| Take over a browser | Dock and interact with the live page |
| Start new sessions | Including from a folder or project |

## The composer

The composer is expanded by default on a fresh session, so a new session is one tap
from typing.

Voice input sits beside send. Attachments and image thumbnails work the same as on
desktop, and thumbnails open full screen.

## Moving around

- **Swipe** between sessions.
- **Swipe from the edge** on the first session to start a new one.
- **Sessions / Workspace** switches between session cards and the active panes.

The inbox opens a drawer on tap, with actions inside it.

## Browsers on mobile

A browser pane can go full screen. When the keyboard appears it overlays rather than
squashing the page, so you can type into a form without losing the view.

## Performance

Hidden panes stop working. Terminals, browsers, and transcripts you are not looking at
suspend their rendering and polling, so a phone is not burning battery on twenty
invisible sessions.

Reduced-motion preferences are respected — animated states stay still.

## What is deliberately absent

There are no notification sounds. Axis does not chime when something finishes.

Push notifications are available if you want to know when something needs you.
