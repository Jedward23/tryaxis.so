**Learn lane · Guided mission**

Choose one real, low-risk outcome. You do not need a perfect prompt. Axis should help
supply the project context, plan, tools, and proof around an ordinary request.

## Mission outcome

By the end, you will have:

- one project with a continuing session,
- one completed piece of work,
- evidence you inspected yourself,
- one useful correction or open item preserved for later.

## 1. Choose the durable home

Open a project that contains the material or system the task belongs to. A project is
more than a folder picker: it scopes the working agreement, relevant memory, work
plans, services, sessions, and saved results.

For a first mission, use reversible work: improve a small page, investigate an error,
organize a report, or review a set of changes.

## 2. Ask normally

Describe what you want as you would to a capable colleague:

```text
The settings page feels slow when it first opens. Find the cause, improve it,
and show me evidence that the real page is faster and still looks right.
```

You supplied the outcome and the observed problem. Axis and the agent should discover
available project rules, inspect the code or source system, form a plan when needed,
choose tools, and identify appropriate proof.

If a fact is essential and only you know it, the agent asks. It should not turn every
discoverable detail into a questionnaire.

## 3. See contextualized execution

The session becomes the continuing thread for this outcome. Open the **Working** fold
to inspect the chronological work: reasoning, reads, commands, edits, browser actions,
and other tool calls.

A multi-step job may show a compact plan above the composer. You can let it run, add a
follow-up to the steering queue, or stop it if the direction is wrong.

## 4. Inspect evidence, not the completion sentence

Open the proof that matches the work:

- a real screenshot for a visual change,
- before/after timings for performance,
- destination state for an external update,
- tests and changed lines for code behavior,
- a saved report or Collection item for durable output.

The agent's summary helps you navigate. It is not itself proof.

## 5. Exercise human judgment

Decide whether the outcome is right, whether the trade-off is acceptable, and whether
any consequential next action is authorized. If the work needs a login, message send,
deployment, purchase, deletion, or similarly scoped authority, Axis should stop at a
clear human checkpoint.

A denial leaves that proposed action unexecuted. An approval authorizes only the action
and scope described by the gate.

## 6. Make the next session better

Preserve only what should survive:

- Save a durable correction or lesson to [Memory](/docs/memory/).
- Record unfinished work in the shared [work plan](/docs/work-plans/).
- Put a standing rule in the project's [working agreement](/docs/working-agreement/).
- Keep a useful output in [Collections](/docs/artifacts/).

That closes the loop: the next session starts ahead instead of from zero.

## Mission complete when

You can point to the exact session, the exact evidence, the judgment you made, and the
knowledge or open work that will carry forward.
